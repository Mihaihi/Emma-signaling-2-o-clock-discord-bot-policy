Privacy Policy

Last updated: 2026/ 8/ 31/

This Discord bot ("the Bot") does not collect, store, or process any personal data from its users.

Data Collection
The Bot does not collect, log, or retain any user data, message content, server information, or user identifiers. Its functions are limited to:

Automatically sending an image to a text channel once per day, at approximately 2:00 AM (KST), in each server it has been added to
Responding to a manually triggered test command (/테스트전송) that immediately repeats the same image-sending action

No information related to these actions is stored beyond what is temporarily required to complete them.

Data Sharing
Since no data is collected, no data is shared with third parties.

Changes to This Policy
If this policy changes in the future (e.g., if new features requiring data collection are added), this page will be updated accordingly.
